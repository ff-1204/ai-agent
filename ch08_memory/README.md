## 학습 목표

- 단기 메모리와 장기 메모리의 역할 차이를 설명할 수 있다
- 체크포인터로 대화 맥락을 유지하는 챗봇을 만들 수 있다

- Store 기반 장기 메모리로 사용자 정보를 저장·조회·검색하는 개인화 에이전트를 만들 수 있다
