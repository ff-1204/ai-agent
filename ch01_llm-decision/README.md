# Chapter 01 · LLM 기반 의사결정 구조와 에이전트 동작 방식

> Part 01 | AI 에이전트의 개념과 원리

## 학습 목표

- LLM이 에이전트의 '두뇌'로서 어떤 역할을 하는지 설명할 수 있다
- LLM이 다음 행동(액션)을 결정하는 과정을 단계별로 따라갈 수 있다
- 작업 단계를 미리 고정한 워크플로형 구조와, 동적으로 판단하는 자율 에이전트 구조의 차이를 구분할 수 있다

## 이 장의 이해 흐름

네 개 절은 따로 노는 게 아니라 **한 절이 남긴 질문을 다음 절이 푸는** 구조입니다. 순서대로 읽으세요.

```mermaid
graph TD
    Q0["`if` 로는 고객 문의를<br/>분류할 수 없다"] --> S1["<b>1.1</b> LLM이란 무엇인가"]
    S1 --> Q1["분류는 되는데…<br/>답이 자연어라 코드가 못 쓴다"]
    Q1 --> S2["<b>1.2</b> 판단을 받아 내는 법"]
    S2 --> Q2["판단은 했는데…<br/>LLM은 DB를 못 읽는다"]
    Q2 --> S3["<b>1.3</b> 행동으로 잇는 법"]
    S3 --> Q3["루프는 강력한데…<br/>정해진 일에도 써야 하나?"]
    Q3 --> S4["<b>1.4</b> 구조를 고르는 기준"]
    S4 --> N["2장 · 3장으로"]
```

| 절 | 이 절의 질문 | 얻는 것 |
| :--- | :--- | :--- |
| **1.1** | LLM은 도대체 무엇을 하는 물건인가? | LLM이 **잘하는 것과 절대 못 하는 것**의 구분 |
| **1.2** | LLM의 답을 내 코드가 어떻게 받아 쓰지? | **구조화 출력**과 **라우터** |
| **1.3** | 판단은 했는데 실제 일은 누가 하지? | **도구 호출**과 **에이전트의 루프** |
| **1.4** | 항상 루프가 답일까? | **워크플로 vs 자율**을 고르는 기준 |

> **막히면 앞 절로 돌아가세요.** 각 절 맨 앞에 `여기까지 / 이 절의 질문 / 다 읽으면`이 있고, 맨 뒤에 `다음 절로`가 있습니다. 그 두 칸만 이어 읽어도 흐름이 잡힙니다.

### 1장 전체를 한 줄로

> **LLM은 다음 토큰을 고를 뿐이고(1.1) → 그 판단을 코드가 쓸 수 있게 형식을 강제했고(1.2) → 도구로 행동과 이어 루프를 만들었고(1.3) → 그 루프를 쓸지 말지 고르는 기준을 세웠다(1.4).**
